# Pixel Computer Club

Open [Testi/index.html](Testi/index.html) locally. The site uses HTML, local Bootstrap 5.3.8 CSS and a small custom stylesheet. The computer room page also uses a small local JavaScript file for demo seat labels and package previews.

The [project README](Testi/README.md) contains the page list, three visitor journeys, JavaScript hooks and submission instructions. The [quality-pass report](Testi/QUALITY-PASS.md) records the earlier midterm checks and remaining student checks before the final tag.
