# Pixel Computer Club

Open [Testi/index.html](Testi/index.html) locally. The site uses HTML, local Bootstrap 5.3.8 CSS and a small custom stylesheet, with no JavaScript.

The [project README](Testi/README.md) contains the page list, three visitor journeys, future JavaScript hooks and submission instructions. The [quality-pass report](Testi/QUALITY-PASS.md) records the tests and remaining student checks before the final midterm tag.
